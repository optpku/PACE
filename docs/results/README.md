## Featured achievements

| Investigation | Main conclusion | Scope |
|---|---|---|
| [Exact-line-search BFGS](bfgs-q-order.md) | The minimum Q-order is one, and the infimum is attained. | One globally smooth, strongly convex objective and trajectory in every fixed dimension at least two. |
| [Heavy-Ball dynamics](heavy-ball-dynamics.md) | An explicit point has neither the specified certificate nor a nonconstant cycle; a surrounding box has global linear convergence. | The stated two-point certificate family and the corresponding strongly convex, smooth function classes. |
| [Fixed-path sample complexity](path-network-lower-bound.md) | A lower bound with statistical and network terms matches the upper bound's principal polynomial dependencies. | Local linear-span methods on a fixed lazy path; one query and one gossip per node per round; accurate output at every node. |
| [Bilevel optimization with additive noise](bilevel-additive-noise.md) | The optimal precision exponent is two, with a single logarithmic gap. | State-independent additive noise, same-sample one- or two-state queries, and per-return accounting. |

The linked case pages contain problem statements, result summaries, and references in English. Complete proof texts and agent run archives are not included in this collection.
