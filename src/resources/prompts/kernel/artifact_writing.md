# Artifact Writing Guide

Write the artifact as a readable record, beginning with its purpose and exact
literal-target identity. Name the input/source paths, state the claim or
derivation, give its scope and evidence level, and list unresolved bridges,
failed checks, or incomplete conditions. For a proof or construction include
the relevant definitions and the target clauses it addresses. Repeat the
requested output path when the role prompt supplies one.

The Host only selects paths, stores the model text or JSON, and records
provenance. It does not fill missing fields, normalize mathematical values,
infer status, or convert a saved artifact into verification. Only fresh
Auditor/Kernel evidence can support a final mathematical result.
