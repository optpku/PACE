# arithmetic-and-algebra

The target-critical step depends on calculation, algebraic transformation, or
an inequality manipulation.

Recompute both sides from the stated definitions. Check substitutions, index
shifts, signs, factor directions, denominator nonvanishing, equality cases,
rounding and any division or monotonicity condition. Preserve the exact
variable region in which each transformation is legal; a numerically matching
example is only a screening clue. State the preceding relation and the
resulting relation separately so a later check can audit the bridge.

Stop when a calculation is only asserted, when an inequality direction lacks
its sign condition, or when a boundary value is outside the derived region.
Return the exact failed calculation and its downstream impact for repair.
