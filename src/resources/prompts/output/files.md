# Task files

Write the assigned deliverable and necessary supporting files. Keep supplied
originals read-only, with their exact assumptions and verification scope. Keep
each complete research argument in one canonical manuscript. When a standalone
finding contains the proof, the main handoff briefly states its scope and links
to it; memory records a concise delta and references. Without a complete finding,
the assigned main deliverable retains partial reasoning. Self-contained proof
candidates, independent probes and terminal reports retain their own completeness
requirements. Return the assigned path when finished.

Preserve TeX backslashes using raw literals or correct escaping through every
string/JSON/shell layer. The Host batches format and local-link preflight after
delivery. Avoid repeated whole-file scans for presentation alone.
The Host repairs narrowly recognized missing escapes locally before requesting
model assistance. Write literal command names in code or explicit TeX text;
use escaped spacing commands in formulas. Uncertain defects receive a scoped
repair ticket; formatting does not authorize changing mathematical content.
