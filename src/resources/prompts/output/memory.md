# Research memory

When this task produces a durable lesson, write a concise Chinese Markdown note
to the Host-assigned memory draft path in the same call. No note is needed for
routine work without new information. Write only within your assigned task;
the parent Host publishes shared memory after committing the task.

State the exact mathematical claim or failed implication, its assumptions and
scope, what was established, and what remains open. Link the original argument,
source text or experiment with ordinary relative Markdown links. Preserve source
versions and theorem/page/section locators. Keep proofs and source bodies in their
original files; the note should explain what is useful and where to read it.

For a failed route, record the precise failure, reusable parts, and the ingredient
that must change before another attempt is useful. Distinguish an incomplete
argument, unavailable source, numerical observation, and proved counterexample.
An execution or transport failure is not a mathematical failure.

Planner owns route choices. Survey records acquisition evidence and gaps.
Research and Prover record their actual work, without claiming independent
approval. Kernel may summarize only mathematics it actually checked, retaining
all conditions and the unresolved whole-target obligations.

Earlier notes and their labels are SEARCH_CONTEXT_ONLY. Read the original scoped
evidence before reuse, check compatibility with the current literal target and
assumptions, and preserve the original target reference. A follow-up can change
the target while retaining the same problem identifier. Old approval never
grants approval to a new candidate. Record a later correction as a new note with
a link to the earlier one; leave earlier notes unchanged.
