# 理论论文提纲

根据本次用户原话、附加要求和运行目录中的已有研究，生成一份可以直接
指导论文成稿的 paper_outline.md。使用 theory-paper-composition skill
确定论文的贡献、内容范围和论证深度。
论文采用 NeurIPS preprint 格式，不安排 checklist 或投稿问卷。
提纲及拟写论文默认使用英文；仅在用户明确要求其他论文语言时更改。
中文题面、对话和原始材料不构成更改论文语言的要求。

先理解读者、研究问题、语言和格式要求。浏览整个运行目录及历史轮次的
导航，再沿引用读取原始结果、定义、证明、核验与已经取得的文献。
已有研究报告和旧稿可帮助定位材料，原始数学材料及适用核验提供依据。
无需先生成研究报告，不执行新的检索、数学研究或实验。

选择一条有证据支持的研究主线，安排共同支撑它的结果。比较最接近的
已有文献的实际假设与结论，准确定位贡献。材料不足以确认新颖性时，
使用实际支持的定位，不把本次研究未解决的情形称为学界开放问题。

在相关章节明确已有理论、本次复用或重建的论证，以及实际新增的结果。
对外部数学依赖，说明来源具体支持什么，保留已读原文的文件或稳定链接、
版本及定理、小节或页码，供正文作者继续核对。只有摘要、转引或检索线索
时如实说明取得的内容与缺口，按证据支持的范围安排论断和贡献定位。
缺少来源支持的关键推论保持为明确缺口。

提纲开头给出拟题、目标读者、论文要回答的问题及中心贡献。主要结果
应写出可辨认的数学陈述，包括关键假设、结论及必要的定量保证。
说明关键障碍、证明机制和结果之间的依赖。

随后按读者理解顺序安排正文与技术附录。每节说明准备回答的问题、
具体结果、论证如何展开、前后衔接，以及相应原稿、证明与文献位置。
安排所选结果的已有完整证明，不将补做证明作为正文作者的隐含任务。
对影响表述的证据缺口和重要内容取舍，就近说明理由。

结构随数学内容安排，不机械填充固定章节。选定一个主方案，使用自然
Markdown 和相对于指定输出文件的真实来源链接，不输出 JSON。
只交付本次论文提纲，原始成果、数学目标和核验记录保持只读。
完成后返回路径和一句论文主旨。
