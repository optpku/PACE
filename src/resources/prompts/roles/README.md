# Specialist dispatch index

Calling skills are for the Director; each specialist retains its own work prompt
and mathematical methods. Read the relevant skill before issuing a task.

| Specialist | Work to assign | Calling skill |
| --- | --- | --- |
| Survey | Investigate literature, compare sources and check applicability. | [dispatch-survey](../../skills/dispatch-survey/SKILL.md) |
| Framer | Turn an open mathematical request into bounded work items. | [dispatch-framer](../../skills/dispatch-framer/SKILL.md) |
| Planner | Create or update the mathematical route and its dependencies. | [dispatch-planner](../../skills/dispatch-planner/SKILL.md) |
| Research | Attempt a bounded derivation, construction or local repair. | [dispatch-research](../../skills/dispatch-research/SKILL.md) |
| RCI | Explore substantive conjectures, mechanisms or constructions in depth. | [dispatch-rci](../../skills/dispatch-rci/SKILL.md) |
| Prover | Assemble or repair a complete literal-target candidate. | [dispatch-prover](../../skills/dispatch-prover/SKILL.md) |

Report/paper writers are Host writing tasks. Finding reviews and Auditor/Kernel
are independent verification boundaries, outside this dispatch list.
