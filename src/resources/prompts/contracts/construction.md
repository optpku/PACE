# Construction Contract Writing Guide

Describe the constructed object or algorithm in prose: identity, domain,
quantifiers, inputs and outputs, initialization, parameters, transitions or
operations, stopping/edge cases, and conditions at every use site. State the
properties that the proof must establish, the exact source or proof reference
supporting each property, and the unresolved obligations or failed checks.

Keep a source construction as search context until its definition and required
properties are re-established for the current literal target. A prototype,
numerical result, or source blueprint is not a correctness certificate. Do not
invent construction IDs, status fields, schema versions, or verification
claims; use the identifier and output path supplied by the role prompt.
