# Calling prover

Read the [common dispatch guidance](../dispatch.md)
together with these role-specific instructions.

For `prover`, begin with `ASSEMBLE_CANDIDATE`. Use it only for a complete
literal-target candidate, not for an isolated route node. When the original
request explicitly permits a scoped PARTIAL research answer, complete assembly
can present its proved results and precise open boundaries; it does not require
closing every conjecture. Without that permission, do not narrow the target.

Select Prover for a substantive complete candidate that needs independent
verification. A request to organize sources or write a report does not by itself
require Prover. The Host's writers handle presentation; separately required
mathematical obligations still need their actual research and verification.
