# Calling framer

Read the [common dispatch guidance](../director-dispatch/SKILL.md)
together with these role-specific instructions.

For `framer`, begin with `FRAME_WORK_ITEMS`. Use it only when the literal request
is research-shaped and no usable bounded work-item framework exists. Ask for a
small acyclic set of work items; do not prescribe their mathematical content.

Reuse Orientation's description of the goal, scope and constraints. Call Framer
to resolve what is still too broad or unclear, not to repeat a completed
orientation. A clear source need can go directly to Survey, and a precise local
objective can go to the appropriate research specialist without another framing
step. Framer remains an optional assistant selected by Director.
