# Raw Seed: Prior-Outcome-Aware Selection

Use this Skill only when explicit prior accepted, rejected, or blocked refs are
listed in `Files to read`. Do not scan a directory or infer unseen history.

Extract the exact scoped lesson from each relevant prior outcome: direct source
coverage, false implication, vague delta, overclaim, missing definition,
counterexample, or blocked mathematical bridge. A new seed may reuse sound
components but must change the failed mathematical ingredient or answer a
different work-item objective. Renaming symbols is not a new direction.

Prior outcomes are search context. Preserve their recorded scope and do not turn
a blocked route into a theorem-level negative conclusion.
