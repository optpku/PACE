# Literature Policy Validation

Use this Skill only when an explicit literature policy and source-bearing role
output are both supplied. Judge the supplied strings and refs; do not perform a
new search and do not infer novelty from memory.

Report a blocking violation when source evidence uses an excluded publication
period, disallowed source class, excluded query term, or locator outside the
policy. Also block a future-search request that would itself violate the stated
boundary. Merely mentioning the boundary is not a violation.

For each finding, identify the exact field, supplied value, policy condition,
and consequence. If the evidence cannot be checked from the provided inputs,
mark it unresolved rather than treating it as support. This review affects
source admissibility only; it does not judge mathematical truth or proof
acceptance.
