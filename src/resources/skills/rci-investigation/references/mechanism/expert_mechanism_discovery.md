# Mechanism Skill: Expert Discovery

Search for the first candidate-relevant mathematical action around the current
frontier. Useful mechanisms include an inequality, descent or
domination principle, decomposition, invariant, localization certificate,
comparison object, recurrence, coupling, or obstruction calculation.

For an existing exact conjecture, keep its statement fixed and spend research
effort on the missing mechanism. When useful, compare substantively different
approaches against the concrete obstacle, using derivations, examples and
failure tests to select the better supported proposal. A supplied mechanism
is a starting hypothesis, not a commitment. Use the existing phase and repair
limits rather than extending the search indefinitely.

Identify the exact bottleneck, the primitive or accepted dependency inputs, the
mathematical proof object, the first nonroutine move, the intermediate output,
and what remains outside the support boundary. Test one positive and one hostile
instance before proposing it.

Do not choose a mechanism whose output restates the candidate target or an
unproved target assertion. Definition expansion, notation alignment, typing, direct
substitution, and routine bookkeeping are not mechanisms.
