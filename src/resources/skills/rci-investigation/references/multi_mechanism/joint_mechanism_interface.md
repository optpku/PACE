# Joint Mechanism Mathematical Interface

Audit one mechanism at the current candidate. Determine dependencies only from
declared inputs and direct producer refs, never proposal order.

For each dependency, identify the exact producer output and the first inference
that consumes it. Reject circular use of the proposed output or candidate target.
A Critic promotion permits later support composition as
reviewed search context; it is not a proof.

Execute the proof object, key move, equations, and derived steps. Check domains,
quantifiers, signs, constants, limiting regimes, and equality cases. The output
must follow from declared inputs within the stated support boundary. The
boundary names the intermediate actually supported and what the mechanism does
not prove.

Correctness, noncircularity, interface honesty, and candidate usefulness are
blocking. Novelty, standalone value, and difficulty are advisory.
