# Combined Support Audit

Recompute the support supplied by the selected promoted mechanisms without
demanding complete target closure.

- Follow explicit dependencies in order and reject unavailable, cyclic,
  mismatched, or dishonest inputs.
- Permit independent selected mechanisms; they need not all feed one terminal
  mechanism.
- Check simultaneous scope, parameters, quantifiers, domains, constants, and
  endpoint regimes.
- Remove each selected mechanism in turn and state what substantive support is
  lost.
- Treat definition expansion, notation aliases, type and domain normalization,
  and direct substitution as routine projection.

Support is substantive partial only when correct nonredundant intermediates
materially help while the target remains open. It is insufficient when no such
intermediate helps. It is full coverage when support plus routine
projection completes the target; that case must be hardened or quarantined, not
presented as open.
