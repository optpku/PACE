# Reuse evidence with its conditions

## When to use and inputs

Use when a candidate changes, a previously proved finding seems relevant, or
a route imports a result from research memory. Read the original result and
proof, its review/version references, and the exact current consumer claim.
Respect phase input restrictions; this method does not authorize blind probes
to retrieve hidden history.

## Procedure

1. Separate the old mathematical statement from its previous use in a route.
2. Match objects, quantifiers, parameter dependencies, region, and conclusion.
3. Prove every old hypothesis in the new setting, or mark the failed bridge.
4. Derive the consumer's required relation from the old conclusion. Preserve
   the direction of implications and identify the exact object being reused.
5. Record the source/version and new applicability argument in the assigned
   proof or memory note. Keep failed uses distinct from the old result itself.

## Output and handoff

Return an explicit scoped application, or the first missing hypothesis or
conclusion bridge and the downstream claims it blocks. A changed candidate
reopens affected applications for mathematical review; it does not erase valid
old results, and an old PASS does not certify a new target.
