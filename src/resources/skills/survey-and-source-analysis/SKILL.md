# Survey and source analysis

## When to use and inputs

Use for an assigned literature question, a missing applicability condition, or
a comparison with known results. Start with the target objects, assumptions,
quantifiers, desired conclusion, and already acquired sources.

## Procedure

1. Turn the mathematical gap into a precise query: object class, parameter
   regime, relation sought, and plausible alternative terminology.
2. Inspect the closest primary source. Record whether you have the full proof,
   a theorem statement, or only an abstract/snippet. Preserve an exact locator.
3. Extract the hypotheses and conclusion, then trace where the proof uses the
   hypotheses relevant to the present gap. A matching formula is insufficient.
4. Compare source and target objects, topology, oracle model, parameter ranges,
   and constant dependencies. Distinguish direct applicability, a missing
   bridge, a useful analogy, and an actual contradiction.
5. Save the acquired material and source report in the assigned locations.
   Preserve the actual bibliographic identity and version; keep unknown details
   explicit. Explain what the sources cover and the next unresolved question.

Only Survey may acquire external sources, and only when the Host enables
retrieval. Other mathematical and editorial roles use already acquired local
material and record missing sources for Survey; this method grants no extra
retrieval authority. If access fails, preserve the source lead and missing
passage; do not infer novelty or falsity from failed retrieval.

## Output and handoff

Return source references, precise theorem/proof locators, the visible statement,
and a source-to-target comparison. Explain what Planner or Research must prove
before use. Sources guide the research; Survey does not approve the final proof.
