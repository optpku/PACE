# Compare a source at the point of use

Read the claim the downstream proof needs before searching. A request for a
global complexity bound may contain several different source needs: a local
descent estimate, a continuation lemma, and a count of oracle evaluations.
Search each missing relation at its own scope, rather than importing a whole
algorithm because its headline rate resembles the target.

For each promising result, record in the assigned report:

| Item | What the reader needs |
| --- | --- |
| Identity | Actual title/authors and a stable acquired-source reference. |
| Locator | Theorem/equation number or exact section/page in the version read. |
| Access | Full argument, statement only, abstract, or unverified lead. |
| Statement | Objects, quantifiers, hypotheses, conclusion, parameter range. |
| Proof use | Where the relevant assumption enters the derivation. |
| Transfer | Object correspondence and hypotheses proved in the target setting. |
| Gap | The exact missing condition, estimate, or unavailable source passage. |

These are explanatory items, not a new required JSON schema. Follow the
assigned Survey output format. Quote only the needed passage; summarize the
rest faithfully and retain a retrievable reference.

A source may be relevant without applying. An existence theorem need not give
an implementable oracle; an attained minimum differs from an infimum; a bound
with dimension-dependent constants is not dimension free. When only the proof
idea transfers, describe the idea and identify the new derivation required.

Combine evidence at the level it supports. Agreement among abstracts does not
replace a proof passage. Failure to find a result leaves the literature question
open. It is never by itself evidence that a conjecture is new or unsolved.
