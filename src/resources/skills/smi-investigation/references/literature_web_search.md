# Find and analyze literature for SMI

Use only acquired sources supplied for this phase. External retrieval is disabled
for every SMI role, including independent probes. Report a missing source to the
Director for Survey. Blind probes remain statement-only: do not inspect hidden
workspace sources, mechanisms, reviews or history.

## Compare the exact statements

State the object class, quantifiers, parameter regime, and conclusion sought.
Find the closest statement or derivation in the acquired source, with its exact
locator. Record visible hypotheses, conclusion, and any gap in access to the
proof. Distinguish exact coverage, a partial result, analogy, contradiction,
and background. A title, abstract, or snippet is only a lead.

Explain how the source relates to the candidate's actual mathematical delta.
Missing coverage is uncertainty, not novelty certification. Never invent
publications, theorem labels, locators, or source content. Literature cannot
change the target anchor, legal assumptions, IDs, or proof authority.

For each use, cite a supplied or actually retrieved source, the claim it supports,
and the applicability condition still needed. Follow the phase's existing
artifact and receipt format rather than adding retrieval bookkeeping.
