# Mechanism Skill: Critic-Guided Repair

Use this Skill when Frontier Explorer receives a Mechanism Critic `REPAIR`
brief. The Critic diagnoses the defect; Explorer owns the revised mechanism.

Preserve the mechanism ID and candidate unless the brief explicitly identifies
an interface misstatement that can be corrected without changing the
mathematical move. Repair the statement, declared inputs, output, proof object,
dependency bindings, and support boundary as needed. Re-run a positive and a
hostile mathematical check.

Narrow an overclaimed output, remove circular premises, correct signs or
domains, bind an existing accepted dependency exactly, or expose an unresolved
obstruction. Do not paste the Critic's prose as the mechanism, add assumptions,
delete an objection by relabeling it solved, change the candidate frontier, or
promote the repair yourself. If the repair needs a different mathematical move,
leave the current mechanism rejected so Explorer can use a distinct mechanism
slot.
