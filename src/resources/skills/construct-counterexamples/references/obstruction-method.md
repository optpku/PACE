# From obstruction to target

Use this method when a failed local relation reveals a possible uncontrolled
parameter or a mismatch between a witness and the object actually used.
Fix the challenged relation and the literal target separately. Write the
residual negation with its method, parameter, dimension and probability scope.

Find a structured family that holds the stated parameters fixed while varying
the suspected hidden quantity. Compute the selected quantity and the permitted
witness separately. Verify that every member remains in the original class:
regularity, attainment, initialization, domain and oracle conditions all stay
attached to the formulas. A convenient small example is a diagnostic until
these checks and the target-level violation are supplied.

For a pointwise implication, calculate the strict violation. For an algorithmic
or complexity claim, a large gradient or a failed update is insufficient: show
that every method in the challenged class faces the required difficulty.
One possible route is to embed a hard core and simulate the full oracle
transcript. Derive which calls disclose core information, which auxiliary calls
disclose none, and why the reported error controls the core error. Establish
the underlying hard-core theorem or leave that dependency unresolved.

Preserve the quantifier order when letting the hidden parameter vary. Exclude
universal constants only by keeping their permitted dependencies fixed; keep
dimension, randomness and charged resources explicit. A deterministic transcript
argument alone does not establish a randomized lower bound.

If the family only refutes the route's stronger bridge, retain possible weaker
estimates or alternative methods. If a target-level reduction is still missing,
return the admissible obstruction with that exact obligation. Do not infer
impossibility from the absence of a successful positive route.

**Handoff:** state the fixed parameters, varying family, verified assumptions,
local violation, target-level reduction if proved, and the strongest scope
actually reached. Only a complete independently checked argument resolves the
literal target.
