# NeurIPS 2026 style package

`neurips_2026.sty` is copied without modification from the official
[NeurIPS 2026 formatting archive](https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip),
retrieved on 2026-10-25. The upstream authorship comments are retained.
This upstream style is kept separate from PACE’s Apache-2.0 licensing;
its original authorship comments are retained.

Only the style package is included. The upstream submission example and
checklist are not part of this distribution. Papers use the preprint layout
and suppress its first-page notice in their own preamble.
