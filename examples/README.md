# Example

[Home](../README.md)

The single included [quickstart](quickstart/README.md) proves that the square of an even integer is divisible by four. This input completed the full workflow with a `PASS` verdict during release validation; run artifacts are not bundled.

First complete [installation](../docs/installation.md): obtain `main`, install PACE, configure Codex, and run `pace doctor`. This proof-mode example needs no TeX or Poppler. PDF tools and `pace doctor --pdf` are needed for research-mode paper delivery or explicitly requested manuscripts. Commands assume the repository root and an active installation of PACE.

The batch templates reuse the same input. General instructions for your own research questions, continuation, recovery, and batch execution are in the [user guide](../docs/user-guide.md).
